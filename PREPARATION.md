# Tealium Connector — Preparation

**Category:** C36. Customer Data Platform (CDP)  
**Vendor URL:** https://tealium.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Tealium** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C36. Customer Data Platform (CDP)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **веб-аналитик** сталкивается с задачей: **управление тегами, сбор событий в реальном времени (EventStream) и обогащение профилей посетителей (AudienceStream)**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Tealium переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **веб-аналитик, специалист по интеграциям, CDP-администратор**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `аутентификация через API-токен -> чтение правил атрибуции посетителя -> мониторинг доставки событий`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Tealium.
